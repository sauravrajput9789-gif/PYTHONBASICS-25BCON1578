# PYTHONBASICS-25BCON1578

A structured collection of core Python programs covering fundamental programming concepts, standard data structures, mathematical computations, and logic-building exercises.

---

## 📌 Description

This repository serves as a foundational Python practical lab and reference guide. It demonstrates essential programming building blocks including control flow, iteration patterns, recursion/loops for mathematical sequences, and common operations on built-in collections (lists and dictionaries).

---

## 📂 Programs Included

The repository contains the following Python scripts:

| File Name | Description | Concepts Covered |
| :--- | :--- | :--- |
| `dictionary.py` | Implementation and operations on Python dictionaries. | Key-value mapping, lookups, dictionary methods, and iteration. |
| `factorial.py.PY` | Program to calculate the factorial of a given non-negative integer. | Loops / recursion, arithmetic logic, and input handling. |
| `fibonacci.py` | Generates the Fibonacci sequence up to *N* terms or a given threshold. | Iterative series generation, state tracking, and sequence logic. |
| `list.py` | Demonstration of basic list operations and manipulations. | Indexing, slicing, appending, searching, and list methods. |
| `mulitiplication.py` | Program to generate multiplication tables or compute products. | Loops, formatted output, and basic arithmetic. |
| `pattern.py` | Console-based shape/pattern generation (e.g., star/number pyramids). | Nested loops, formatting, and console printing. |

---

## ⚙️ Requirements & Dependencies

- **Python Version**: Python 3.6+ (Python 3.x recommended)
- **External Dependencies**: None. All programs rely exclusively on standard built-in Python features and require no external `pip` installations.
